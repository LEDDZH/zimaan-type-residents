澳門檔案 / 字民

每一個字，
都曾在街上生活。

「字」是對象，「民」是街頭日常與市民性。招牌、便條、街牌、告示，構成不同語言、筆跡與材質共存的城市。

這件作品把同一組檔案分成兩種讀法：INDEX 讓記錄可以被查找，ReDesign 讓原字形在粒子中再次相遇。粒子不是額外的裝飾，而是從觀看進入一筆具體記錄的路徑。

資料快照為 2026-10-20，不自動更新。地區由原描述中的地名匹配，並非經緯度定位；原檔案含未核實 OCR，網站不以它替代正式轉錄。部分提取圖與照片為左右配對、部分為上下配對；ReDesign 依圖像方向擷取字形區，裁切仍可於後續打樣校正。

攝像頭只在你點擊並授權後開啟，手部辨識在瀏覽器本機處理。本網站不錄影、不上傳攝像頭畫面；關閉手勢即停止影像串流。原照片、字形提取與標題歸原收集者。

INTERACTION GUIDE

用手，把文字喚近。

01 / 鼠標與觸屏

移動指標撥散粒子；按住聚攏，拖曳旋轉。滾輪或雙指縮放。點選編號節點查看原檔案。

02 / 攝像頭手勢

手掌移動帶動粒子；張掌撥散、握拳聚攏。拇指與食指捏合選取；雙手拉開／靠近縮放。先將手停在目標旁，再捏合。

03 / INDEX 檢索

輸入文字、街名、帳號或 ID，篩選結果會同步留在粒子星環。也可切到 INDEX，以圖片和原始描述逐一查閱。

04 / ReDesign 創作

在詳情選「字形粒子化」，或從 ReDesign 換一位字民。切換字形、星環、街巷；可下載當前畫面 PNG。

鍵盤：/ 搜尋，1 浮游，2 INDEX，3 ReDesign，空白鍵暫停，Esc 關閉視窗。若攝像頭被拒絕或裝置不支援，可完整使用鼠標／觸屏瀏覽。手勢辨識受光線與遮擋影響。
